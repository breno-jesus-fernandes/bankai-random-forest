# Bankai Random Forest

`bankai-random-forest` is a GPL-3.0-or-later, scikit-learn-compatible random
forest package. Its Rust core starts from XRF and will evolve toward additional
backends, including a histogram-based random forest.

The implementation is in its bootstrap phase. The project roadmap, architectural
decisions, TDD protocol, and release gates are tracked in
[`docs/ROADMAP.md`](docs/ROADMAP.md).
